name: american-english
description: Enforce American English spelling in code, comments, and strings
---

This repository uses American English. Apply these rules to all text you write or modify — identifiers, comments, Javadoc, string literals, log messages, and error messages.

## Common corrections

| British | American |
|---------|----------|
| colour | color |
| behaviour | behavior |
| initialise / initialising | initialize / initializing |
| serialise / serialising | serialize / serializing |
| authorise / authorising | authorize / authorizing |
| recognise / recognising | recognize / recognizing |
| organise / organising | organize / organizing |
| analyse / analysing | analyze / analyzing |
| centre | center |
| metre | meter |
| fibre | fiber |
| licence (noun/verb) | license |
| defence | defense |
| offence | offense |
| programme | program |
| catalogue | catalog |
| dialogue | dialog |
| travelled / travelling | traveled / traveling |
| cancelled / cancelling | canceled / canceling |

When reviewing or editing existing code, flag any British spelling you encounter.
